Custom Web Development

Websites, web apps, and landing pages that actually work.

I build fast, responsive, and easy-to-maintain web solutions using HTML, CSS, JavaScript, Python, and PHP.

Scope

Custom web development covers everything from a single landing page to a full-featured web application. I focus on clean code, fast load times, and responsive layouts that work on mobile and desktop. Every build starts with understanding what you actually need, then I spec, build, test, and document it.

  • Static websites and landing pages
  • Dynamic web apps with backend logic
  • Progressive web apps
  • API-driven frontends
  • Performance and accessibility optimisation

Process

Every web project follows the same simple flow: requirements call, proposal, build, test, launch. I use plain HTML, CSS, and JavaScript unless a framework makes more sense, and I keep the stack as simple as possible so you or your team can maintain it later.

  • Requirements call and written proposal
  • Design and tech selection
  • Build and iterate
  • Functional and integration testing
  • Deploy and handover with docs

Tech

My core stack is HTML, CSS, JavaScript, Python, PHP, and REST APIs. I also use Cloudflare Workers for lightweight edge tasks, NGINX for routing, and Git for version control. For databases, I work with SQL, JSON, and CSV depending on the project.

Pricing

Simple websites start from $500 AUD. Custom web apps typically start from $1,000 AUD depending on features. I provide a fixed quote after the requirements call so there are no surprises.

FAQ

How long does a website take?

Simple sites: 1-2 weeks. Custom apps: 4-8 weeks. Rush jobs may be possible depending on current workload.

Do you handle hosting and domain setup?

Yes. I can deploy to your existing hosting, set up Cloudflare, or recommend a provider that fits your needs and budget.

Will I be able to update the site myself?

Absolutely. I build with maintainability in mind and provide clear documentation so you or your team can make updates without me.
